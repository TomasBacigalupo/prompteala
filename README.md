# Cómo llegué a los LLM locales

Landing companion for Tomás Bacigalupo’s talk. Open it beside the stage and jump chapters as you speak.

```bash
npm install
npm run dev
```

Then open [http://127.0.0.1:5173](http://127.0.0.1:5173).

**On stage:** click the left/right edges of the slide (or use `←` `→` / `J` `K` / Space) to move between slides. Sidebar jumps to any chapter. `P` hides the chrome. `ES` / `EN` switches language.
